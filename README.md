# Excel Data Analysis Project - Week 1

## Overview
This repository contains data analysis work completed during the **Data Technician Skills Bootcamp**. The project focuses on processing, analyzing, and visualizing retail sales data, bike sales, and human resources datasets using advanced Excel functionalities.

---

## Key Skills & Excel Functions Demonstrated

### 1. Data Cleaning & Transformation
* **Filtering & Sorting:** Structured datasets for efficient exploration and reporting.
* **Text & Date Functions:** Used `DATE()`, `MONTH()`, `YEAR()`, and `UNIQUE()` to extract timeframe dynamics and identify unique items.

### 2. Formulas & Calculations
* **Aggregation:** Applied `SUM()`, `AVERAGE()`, `SUMIF()`, and `AVERAGEIF()` for conditional metrics.
* **Lookup & Logic:** Implemented `VLOOKUP()` for cross-table data matching and the `SWITCH()` function for clean category mapping.

### 3. Data Visualization & Summarization
* **PivotTables:** Created dynamic summary tables to evaluate key metrics across retail segments.
* **Charts & Dashboards:** Built visual charts to showcase sales distribution and trend analyses.
